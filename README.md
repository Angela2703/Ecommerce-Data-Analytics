# E-Commerce Data Analytics Project

## Project Overview
An end-to-end e-commerce data analysis project focused on transforming raw transaction data into meaningful business insights.

The project involves data cleaning, SQL-based analysis and interactive Power BI dashboards to understand sales performance, profitability, customer behaviour and product trends.

**Analysis Period:** 2011–2014

## Tools & Technologies
- Microsoft Excel
- MySQL
- Power BI
- Power Query
- DAX

## Project Analysis

### 1. Excel
- Data cleaning and preprocessing
- Data organization
- Exploratory analysis

### 2. SQL
- Sales and profit analysis
- Category and sub-category analysis
- Shipping mode analysis
- Discount analysis
- Negative profit identification

### 3. Power BI
- Executive Overview Dashboard
- Sales Analysis Dashboard
- Product & Customer Insights Dashboard

## Key Business Insights
- Technology generated the highest category sales.
- Consumer segment contributed the highest sales.
- APAC was the leading market by sales.
- Central region recorded the highest regional sales.
- Tables recorded negative overall profit.

## Project Deliverables
- Cleaned dataset
- SQL analysis queries
- Interactive Power BI dashboard
- E-Commerce Business Insights Report
