# Power BI Dashboard

This folder contains the interactive Power BI dashboard developed to analyse e-commerce business performance.

### Dashboard Pages
1. Executive Overview
2. Sales Analysis
3. Product & Customer Insights

### Key Metrics
- Total Sales
- Total Profit
- Average Discount
- Total Orders

### Analysis
- Regional and market-wise sales
- Monthly sales trends
- Category performance
- Segment-wise sales
- Product and customer insights
- Sub-category profitability
