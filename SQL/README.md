# SQL Analysis

This folder contains SQL queries developed to analyse e-commerce transaction data and extract meaningful business insights.

### Analysis Performed
- Sales and profit analysis
- Category and sub-category performance
- Average discount analysis
- Orders with negative profits
- Ship mode usage analysis
- Customer and regional analysis
- Business performance insights

### SQL Concepts Used
- SELECT, WHERE and ORDER BY
- GROUP BY and aggregate functions
- Joins
- Subqueries
- CTEs
- Window Functions
